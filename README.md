# Ohm's Law and Electrical Power Calculator

## What it does

This Python program calculates voltage, current, resistance, and electrical power using Ohm's Law. It also provides a formula guide, records calculations with their date and time, and allows the user to view, clear, or export the current session's calculation history.

## How to run it

Install Python 3, then run:

```bash
python ohms_law.py
```

## My own twist

I added a calculation-history feature. It records each result with its date and time. Users can view the history, clear it after confirmation, or export it to a text file.
